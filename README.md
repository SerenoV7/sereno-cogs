# Requirements

- A working instance of [Red](https://github.com/Cog-Creators/Red-DiscordBot).

# Installation

Run the following command in Discord: `[p]repo add sereno-cogs https://github.com/serenov7/sereno-cogs`

# Available cogs

| Name | Version | Description |
|:-----|:--------|:------------|
| DeadByQueue | 0.1.0 | Fetch Dead By Daylight queue times with configurable regions |
